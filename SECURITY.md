# Security

This crate loads a native library and forwards paths and file bytes to it. Report defects in that wrapper here. Defects in Lore itself belong to the [Lore security policy](https://github.com/EpicGames/lore/blob/main/SECURITY.md). This repository is not an Epic Games channel and has no bug bounty.

Please include the Lore library version (`lore_version`), the operating system, and a description that does not contain credentials. The SDK's local API does not accept tokens. Do not send any.
